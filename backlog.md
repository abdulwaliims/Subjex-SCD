\# Product Backlog — Subjex



\## High Priority

\- User registration and login (JWT auth)

\- CRUD for Subjects

\- CRUD for Notebooks (scoped to a Subject)

\- CRUD for Notes (scoped to a Notebook, markdown body)

\- Per-user data isolation (authorization checks on all routes)



\## Medium Priority

\- Cascading delete (Subject → Notebooks → Notes)

\- Basic frontend UI for navigating the hierarchy

\- Cloud deployment (AWS, via Terraform)



\## Low Priority

\- Note sorting/ordering within a notebook

\- Basic profile management (change password)
